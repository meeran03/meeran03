## Featured projects

### Agent Eval Harness

A framework for evaluating LLM agents on tool-use tasks, scoring outputs, tracing failures, and separating model failures from harness or infrastructure failures.

**Focus:** evals, tool use, traces, reliability, failure classification

### Voice Agent Observability

A monitoring and tracing layer for real-time voice agents, focused on STT/LLM/TTS latency, dropped calls, interruptions, tool-call failures, and conversation-level reliability.

**Focus:** voice AI, observability, latency budgets, production debugging

### Hybrid Search with Postgres

A retrieval project using Postgres, pgvector, embeddings, and hybrid search for LLM applications.

**Focus:** RAG, search quality, embeddings, Postgres, backend APIs

### Assistant Streaming with FastAPI

A FastAPI project demonstrating asynchronous LLM response streaming and function calling.

**Focus:** streaming, async Python, function calling, backend architecture
