## Projects I’m building toward

### Agent Eval Harness
A framework for evaluating LLM agents on tool-use tasks, tracing failures, scoring outputs, and separating model failures from infrastructure or harness failures.

### Voice Agent Observability
A monitoring and tracing layer for real-time voice agents, focused on latency budgets, STT/LLM/TTS timing, tool-call failures, dropped calls, and conversation-level reliability.

### Hybrid Search with Postgres
A retrieval example using Postgres, pgvector, embeddings, and hybrid search for LLM applications.

### Assistant Streaming with FastAPI
A FastAPI project demonstrating asynchronous LLM response streaming and function calling.
